# Smart Diagnostics for Plant Diseases

This project presents an AI-powered diagnostic system designed to detect and localize plant diseases in potato and pepper crops.

The system leverages deep learning models to analyze plant images and identify disease patterns with high accuracy. Multiple architectures were implemented, including CNN, DenseNet for classification, and Mask R-CNN for precise disease localization.

To make the solution practical and user-friendly, the trained models were integrated into a Flask-based web application. This allows farmers or users to upload plant images and receive real-time diagnostic results through a simple interface.

# Models Used
- Convolutional Neural Networks (CNN)
- DenseNet (for classification)
- Mask R-CNN (for disease localization)

# Technologies
- Python
- TensorFlow / PyTorch
- OpenCV
- Flask
- Deep Learning & Computer Vision techniques

# Key Features
- Disease detection from plant images
- Pixel-level localization using Mask R-CNN
- Real-time predictions via web interface
- User-friendly design for non-technical users

# Impact
The system enhances early disease detection, helping farmers take timely action and potentially reduce crop losses.
